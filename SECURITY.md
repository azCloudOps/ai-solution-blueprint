# Security policy

AI Solution Blueprint runs entirely on the user's machine. It has no server component, stores answers only in the browser's local storage or in files the user writes, and makes no network calls.

## Supported versions

The latest minor release receives fixes. Older versions should upgrade.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub private vulnerability reporting on this repository (Security tab, "Report a vulnerability"). Include steps to reproduce and the affected version.

Examples of in-scope issues: script injection through imported answers files or share links, unsafe output in generated Markdown or SVG, supply chain concerns in the release workflow.
